## Project Summary

**PDF Export Pro** is a Chrome browser extension (Manifest V3) that lets users export any webpage to a clean, well-formatted PDF. It uses Mozilla Readability for article extraction, html2canvas for DOM rendering, and jsPDF for PDF construction. The extension is written in vanilla JavaScript with no build toolchain.

## Architecture & Data Flow

### Component responsibilities

| File | Runs where | Does what |
|------|-----------|-----------|
| `manifest.json` | Chrome | Declares permissions, content scripts, popup, service worker |
| `background.js` | Service worker | Relays messages between popup and content; persists options in `chrome.storage.sync` |
| `content.js` | Active tab (page) | Cleans DOM, runs Readability, renders canvas, generates PDF |
| `popup.js` | Extension popup | Reads/writes options, sends export/selection commands |

### Message protocol

All messages follow this shape:

```js
// popup → background → content
{ target: 'content', action: 'EXPORT_PDF', options: { ... } }

// popup → background (local)
{ target: 'background', action: 'SAVE_OPTIONS', options: { ... } }
```

`background.js` routes messages by the `target` field. Responses always follow `{ success: boolean, ... }`.

**Defined actions:**

| Action | Direction | Payload | Response |
|--------|-----------|---------|----------|
| `EXPORT_PDF` | popup → content | `options` object | `{ success }` |
| `ENABLE_SELECTION` | popup → content | — | `{ success, region? }` after mouse-up |
| `DISABLE_SELECTION` | popup → content | — | `{ success }` |
| `PING` | popup → content | — | `{ pong: true }` |
| `SAVE_OPTIONS` | popup → background | `options` | `{ success }` |
| `LOAD_OPTIONS` | popup → background | — | `{ success, options }` |

### Export pipeline (content.js)

```
exportPDF(options)
  ├── buildReadableClone()   ← if useReadability && word count > 200
  │     └── new Readability(docClone).parse()
  │         → styled <div> with article title, byline, body
  ├── buildCleanedClone()    ← fallback or full-page mode
  │     └── document.body.cloneNode(true)
  │         → removeDisruptiveElements()  (JUNK_SELECTORS + fixed/sticky)
  ├── captureRegion(region)  ← if selectionRegion set
  │     └── collect intersecting elements → container div
  │
  ├── html2canvas(mount, { scale:2, useCORS:true })
  │     → HTMLCanvasElement
  │
  └── buildPDF(canvas, opts)
        ├── Slice canvas into page-height strips
        ├── pdf.addImage(jpegSlice, ...)  per page
        ├── _addHeaderFooter(...)         if headerFooter enabled
        └── pdf.save(filename)
```

### Selection mode (content.js)

`enableSelectionMode(sendResponse)` overlays the page with a semi-transparent `position:fixed` div, listens for mousedown/mousemove/mouseup to draw a selection rectangle, then calls `sendResponse` with the region in **document** coordinates (viewport + scroll offset). The popup then calls `EXPORT_PDF` with `selectionRegion` set.

## Key Conventions

### No build step

This project intentionally has **no bundler, no transpiler, no npm**. All JS is plain ES2020 compatible with Chrome's V8. Do not introduce TypeScript, JSX, Webpack, Vite, or similar tooling unless explicitly requested.

### No framework

Popup UI is written with raw DOM APIs. Do not introduce React, Vue, or any UI framework.

### Error handling pattern

- Every `chrome.runtime.sendMessage` callback checks `chrome.runtime.lastError`.
- Async functions in `content.js` use `try/finally` to always hide the loader.
- Errors propagate as `{ success: false, error: string }` response objects — never as thrown exceptions across message boundaries.

### DOM cloning rule

Readability requires a cloned document, not the live one, because it mutates its input. Always pass `document.cloneNode(true)` to `new Readability(...)`.

### Selectors

`JUNK_SELECTORS` in `content.js` is the canonical list of heuristic removal patterns. When adding new patterns, add them there with a comment grouping them by category (ads, navbars, banners, etc.).

### CSS in popup

Styles use CSS custom properties defined on `:root` in `popup.css`. Colours, radii, and shadows all reference variables. When changing the visual theme, update the `:root` block only.

### Icon sizes

Chrome requires exactly `16`, `32`, `48`, and `128` px PNG icons referenced in `manifest.json`. The `generate-icons.js` script produces all four. If replacing icons, maintain these exact sizes.

## Third-Party Libraries

| Library | CDN URL | Role |
|---------|---------|------|
| `@mozilla/readability` `0.5.0` | jsDelivr | Article-content extraction |
| `html2canvas` `1.4.1` | jsDelivr | Renders DOM subtree to `<canvas>` |
| `jsPDF` `2.5.1` | jsDelivr | Builds multi-page PDF from canvas data |

Libraries are loaded as **content scripts** (listed in `manifest.json`) so their globals (`Readability`, `html2canvas`, `window.jspdf`) are available to `content.js` at `document_idle`.

When upgrading a library version, update both `setup.sh` (CDN URL) and this file (version column above).

## Permissions Used

| Permission | Why |
|------------|-----|
| `activeTab` | Access the current tab's URL and inject scripts |
| `scripting` | Dynamic script injection fallback (background.js) |
| `storage` | Persist user options in `chrome.storage.sync` |
| `downloads` | (Declared for future use; jsPDF's `save()` uses `<a download>` internally) |

Avoid adding permissions not listed here. Each new permission requires justification in the Chrome Web Store review.

## Common Development Tasks

### Reload after editing

Chrome does not hot-reload extensions. After any change:
1. Go to `chrome://extensions`
2. Click the **↻** refresh icon on the PDF Export Pro card
3. Close and reopen the popup or refresh the target tab

### Test on a specific site

Open the site, then open the extension popup. Check the browser console (`F12 → Console`) on **both** the popup (right-click the popup → Inspect) and the page for logged errors.

### Adding a new export option

1. Add the control to `popup.html`
2. Style it in `popup.css`
3. Read it in `collectOptions()` in `popup.js`
4. Destructure it in `exportPDF(options)` in `content.js`
5. Update the options table in `README.md` and this file

### Changing the junk-removal heuristics

Edit `JUNK_SELECTORS` in `content.js`. Group new entries by category (ads, navbars, etc.) with an inline comment. Test on at least 5 different major news/blog sites after any change.

- Batch / bulk export across multiple tabs
- Firefox or Safari support
- OAuth or user accounts
- Background PDF queue
- Build system / bundler
